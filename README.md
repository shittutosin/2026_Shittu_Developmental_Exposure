**Early-Life Polycyclic Aromatic Hydrocarbon Exposure Leaves a Persistent Functional Imprint on the Adult Gut Microbiome**

**Overview**<br>
This repository contains R scripts used for statistical analyses and data visualization in this study. 

**Analyses**<br>
The repository includes scripts for analyzing and visualizing data for:<br>

-Gut microbial community composition (long-read 16S rRNA gene sequencing)<br>
-Gut microbial metaproteomics<br>
-Hepatic cytochrome P450 chemoproteomics<br>
-Gut microbial metabolomics<br>
